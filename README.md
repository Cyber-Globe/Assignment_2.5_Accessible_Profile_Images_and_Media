# Accessible Profile Images and Media

A simple personal profile page created as part of the Tech-Prophet Mentorship HTML Foundations assignment. It introduces Ojei Kelvin and showcases profile and workspace images, an audio track, and an introductory video.

## Project files

- `profle.html` — the profile page (open this file in a web browser).
- `images/profile_picture.jpg` — profile portrait.
- `images/banner.png` — page banner.
- `images/workspace.png` — workspace photo and caption.
- `media/tech_prophet.m4a` — audio track.
- `media/CAP1.mp4` — introduction video.

## View the page

Open `profle.html` in a modern web browser. The page uses relative paths for its images and media, so keep the `images` and `media` folders alongside the HTML file.

## Accessibility

The page uses semantic header, main, section, figure, figcaption, and footer elements. Images include alternative text where appropriate, and the audio and video have native browser controls and fallback text.
